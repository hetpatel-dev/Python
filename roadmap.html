Phase 1: Python Fundamentals

1. Python Basics ✅

  • print() and input() functions
  • Comments (#)
  • Variables — assignment and naming rules
  • Basic data types: int, float, str, bool
  • type() function
  • f-strings and string formatting
  • Basic arithmetic operators (+, -, *, /, //, %, **)

2. Variables in Depth ✅

  • Python's data model: objects, identity, type, value
  • id() and is vs ==
  • Mutable vs immutable types
  • Assignment patterns: multiple assignment, swapping, tuple unpacking, star unpacking (*)
  • Augmented assignment (+=, -=, etc.) — in-place vs rebind
  • Type annotations / type hints (name: str = "Alice")
  • del — unbinding names
  • Naming conventions (PEP 8: snake_case, UPPER_CASE, _private)
  • Variable scope (brief intro)

3. Data Types Overview ✅

  • Full type hierarchy: numeric, boolean, text, binary, sequence, set, mapping, None, callable
  • Truthiness — what's False in Python
  • bool() and truth value testing
  • Type conversion constructors (int(), float(), str(), list(), etc.)
  • type() vs isinstance()
  • Hashable concept
  • Mutable vs immutable overview per category
  • Ordered vs unordered

4. Operators in Depth ✅

  • Arithmetic operators: +, -, *, /, //, %, **
  • Comparison operators: ==, !=, <, >, <=, >=
  • Chained comparisons: a < b < c
  • Logical operators: and, or, not — short-circuit evaluation
  • Membership operators: in, not in
  • Identity operators: is, is not
  • Bitwise operators: &, |, ^, ~, <<, >>
  • Operator precedence table
  • Operator overloading concept (mention __add__, etc.)

5. Conditionals ✅

  • if, elif, else
  • Truthiness in conditions
  • Nested conditionals
  • Ternary expression: x if cond else y
  • match/case (structural pattern matching — Python 3.10+)
  • Common patterns: if x is None, if not x, if x in collection

6. Loops ✅

  • for loop — iterating over sequences
  • Looping over different data types: list, tuple, str, dict (.items(), .values()), set
  • range() — start, stop, step
  • while loop
  • break and continue
  • else clause on loops
  • Nested loops
  • enumerate() — getting index + value
  • zip() — iterating multiple sequences
  • reversed() and sorted() — reverse/sorted looping
  • Loop variable scoping (Python's loop variable leaks)
  • pass as placeholder

7. Strings in Depth ✅

  • String indexing and slicing ([start:stop:step], negative indices)
  • String immutability
  • Case methods: .upper(), .lower(), .capitalize(), .title(), .swapcase(), .casefold()
  • Search and replace: .find(), .index(), .count(), .replace(), .startswith(), .endswith(), .removeprefix(), .removesuffix()
  • Split and join: .split(), .rsplit(), .join(), .partition(), .splitlines()
  • Strip and pad: .strip(), .lstrip(), .rstrip(), .center(), .ljust(), .rjust(), .zfill()
  • Classification methods: .isalpha(), .isdigit(), .isalnum(), .isspace(), .islower(), .isupper(), .istitle(), .isascii(), .isidentifier(), .isprintable(), .isdecimal(), .isnumeric()
  • ord() and chr() — character code points
  • Advanced f-strings — format specifiers, = debug, !r/!s/!a conversions
  • Raw strings — r"..." for literal backslashes
  • Multi-line strings with triple quotes
  • Unicode and encoding — .encode(), .decode(), bytes vs str

8. Lists in Depth ✅

  • List construction: [], list(), +, *
  • Indexing and slicing (including slice assignment)
  • List methods: .append(), .extend(), .insert(), .remove(), .pop(), .clear(), .index(), .count(), .reverse(), .copy()
  • list.sort() vs sorted() — key=, reverse=, sort stability
  • Advanced sorting: operator.itemgetter, multi-key sorts
  • List comprehensions: basic, with if, nested for
  • Nested list comprehensions: matrix transposition
  • List as stack (LIFO) — .append() / .pop()
  • List as queue (FIFO) — collections.deque
  • del statement — delete by index, slice, or variable
  • Shallow copy vs deep copy (copy.deepcopy())
  • List pitfalls: modifying during iteration, [[]]*n trap, None-returning methods
  • array module — compact numeric arrays

9. Tuples ✅

  • Tuple basics — commas create tuples, parentheses are optional
  • Tuple packing and unpacking (including starred unpacking on any sequence)
  • Single-element (trailing comma) and empty tuples
  • Tuple immutability (can contain mutable objects; += rebinds)
  • Tuple methods: .count(), .index()
  • Tuple operations: +, *, in, len(), min(), max(), sum(), slicing
  • Lexicographic comparison — multi-key sorting with tuples
  • Hashability — tuples as dict keys and set members
  • Named tuples — collections.namedtuple (_make, _asdict, _replace, _fields)
  • When to use tuples vs lists — heterogeneous records, data integrity, function returns
  • Tuple vs List cheat sheet — mutable, hashable, methods, memory, use cases

10. Dictionaries in Depth ✅

  • Dict basics — {} literal, dict() constructor, dict comprehensions, hashable keys, insertion order guarantee (3.7+), equality ignores order
  • Basic operations — d[key], assignment, del, key in d, len(), list(d), reversed(d), truthiness
  • get() method — safe access with optional default, contrast with bracket access
  • Dict methods — pop(), popitem() (LIFO, 3.7+), setdefault(), update(), clear(), copy(), fromkeys() (mutable default trap)
  • Dict views — keys(), values(), items() — dynamic, set-like operations on keys() (&, |, -, ^), .mapping attribute (3.10+)
  • Iterating dictionaries — for k in d, d.items(), d.values(), sorted(d), reversed(d), enumerate(d.items()), mutation during iteration
  • Dict comprehensions — basic, with if, from zip(), swapping keys/values, filtering
  • Merge & update operators (|, |=) — Python 3.9+, contrast with update()
  • Nested dictionaries — dict of dicts, safe traversal with .get()
  • __missing__ hook & collections.defaultdict — defaultdict(list), defaultdict(int), defaultdict(set), nested defaultdict, vs setdefault()
  • collections.Counter — most_common(), elements(), total(), subtract(), arithmetic (+, -, &, |), unary +/-
  • collections.OrderedDict — move_to_end(), popitem(last=False), order-sensitive equality, LRU cache pattern

11. Sets ✅

  • Set basics — {...} literal vs set() constructor, empty set trap ({} is a dict!), unordered nature, deduplication on creation, hashable element requirement
  • Mutating methods — .add(), .remove() (raises KeyError), .discard() (silent no-op), .pop() (arbitrary element), .clear(), .copy()
  • Membership testing — O(1) average with in vs O(n) for lists, fast deduplication with set(iterable)
  • Set operators — | union, & intersection, - difference, ^ symmetric difference
  • Method equivalents — .union(), .intersection(), .difference(), .symmetric_difference() (accept any iterable)
  • Comparison operators — <= (issubset), < (proper subset), >= (issuperset), > (proper superset)
  • Predicate methods — .isdisjoint(), .issubset(), .issuperset()
  • Update operations — .update() / |=, .intersection_update() / &=, .difference_update() / -=, .symmetric_difference_update() / ^=
  • Set comprehensions — {expr for x in iterable if cond}
  • frozenset — immutable, hashable, usable as dict keys and set members, non-mutating operations only
  • When to use sets — deduplication, membership testing, set math, tracking seen items, excluding items
  • Performance — hash table implementation, O(1) average for membership/insert/delete, memory overhead vs lists

12. Functions in Depth ✅

  • Defining functions — def keyword, function objects, symbol tables, pass placeholder
  • Return values — return statement, implicit None, returning multiple values as tuples
  • Default argument values — evaluation at definition time, the mutable default trap (list/dict defaults), None-and-assign fix
  • Keyword arguments — positional before keyword, no duplicate values, unknown keyword errors
  • Special parameters — positional-only (/), keyword-only (*), combined signatures
  • Arbitrary argument lists — *args (tuple of positional args), **kwargs (dict of keyword args), forwarding pattern
  • Unpacking in calls — * on iterables, ** on dicts
  • Docstrings — PEP 257 conventions, __doc__ attribute, help()
  • Function annotations (type hints) — parameter annotations, return annotations, __annotations__ dict, optional at runtime
  • Functions as first-class objects — assign to variables, pass as arguments, return from functions, store in data structures, callable()
  • Lambda expressions — anonymous functions, restriction to single expression, use with sorted(key=...), map(), filter(), closures
  • Scope: LEGB rule (Local, Enclosing, Global, Built-in), global statement, nonlocal statement in nested functions
  • Functional tools — map(), filter(), functools.reduce()
  • Recursion — base case, recursive case, call stack, recursion limit, sys.setrecursionlimit()

13. Comprehensions ✅

  • List comprehensions — [expr for x in iterable if cond], if filter vs ternary if-else in expression, multiple for clauses (Cartesian product)
  • Dict comprehensions — {k: v for k, v in iterable}, from zip(), swapping keys/values, filtering and transforming
  • Set comprehensions — {expr for x in iterable}, deduplication, empty set trap ({} vs set())
  • Generator expressions — (expr for x in iterable), lazy evaluation, single-use iterators, memory efficiency, sum()/max()/any()/all() with genexps
  • Nested comprehensions — flattening matrices, transposing (zip(*matrix) idiom), readability limits
  • Conditional logic — filter position vs expression position, chained if clauses
  • Walrus operator (:=) — avoid double computation, filter-on-computed-value pattern, scope leakage note
  • When to use vs avoid — one-comprehension guideline, side effects, break/continue, readability trade-offs

14. Error Handling ✅

  • try/except/else/finally — catching and handling exceptions
  • Traceback anatomy — reading and understanding the call stack in error output
  • raise — re-raising, chaining with raise ... from
  • assert — debugging assertions with __debug__ and -O
  • Custom exception classes — inheriting from Exception
  • ExceptionGroup / except* (Python 3.11+) — grouping multiple unrelated exceptions
  • BaseException.add_note() (Python 3.11+) — attaching extra context to exceptions
  • Context managers (with) — __enter__/__exit__, @contextmanager, suppress, parenthesized managers
  • Best practices — EAFP vs LBYL, bare except: dangers, return in finally (PEP 765, 3.14 SyntaxWarning)

15. File I/O ✅

  • open() — modes: r, w, a, x, b, +
  • Context managers (with statement) — automatic cleanup, f.closed
  • Reading: .read(size), .readline(), .readlines(), direct iteration, chunked reading
  • Writing: .write(), .writelines(), append mode
  • File position: .tell(), .seek(offset, whence)
  • Text vs binary mode — encoding, newlines, universal newlines
  • encoding="utf-8" — always specify explicitly (PEP 686)
  • pathlib.Path — object-oriented paths, / operator, properties, read_text(), write_text(), glob(), rglob()
  • os module — os.path, os.stat(), os.listdir(), os.scandir(), os.walk()
  • glob.glob() — pattern matching, recursive search
  • shutil — copy(), copy2(), copytree(), move(), rmtree()
  • tempfile — NamedTemporaryFile(), TemporaryDirectory()
  • io.StringIO / io.BytesIO — in-memory streams
  • csv — csv.reader(), csv.DictReader(), csv.writer(), csv.DictWriter(), newline=''
  • json — json.dump()/json.load(), json.dumps()/json.loads(), type conversion, indent, ensure_ascii
  • Binary files — rb/wb modes, struct module
  • Error handling — FileNotFoundError, PermissionError, graceful patterns
  • Best practices — always use with, always specify encoding, iterate large files, use pathlib

16. Modules & Packages ✅

  • import statement — all forms: import x, from x import y, from x import *, import x as y, from x import y as z, from . import y
  • Absolute vs relative imports — dot notation, __package__ context, main module restriction
  • if __name__ == "__main__" — dual-use modules, testing, CLI interface
  • Creating your own modules — file as module, naming conventions, private namespaces, module-level code runs once
  • Packages — __init__.py purpose, subpackages, namespace packages (no __init__.py)
  • Module search path — sys.path, PYTHONPATH, site-packages, full import search order
  • sys.modules — import cache, caching behavior, re-import vs reload
  • dir() — listing names in a module, filtering, hasattr()
  • __all__ — controlling from module import *, shadowing warning
  • Module attributes — __name__, __file__, __spec__, __path__, __doc__, __dict__
  • Re-exporting with __all__ — clean public API, type checker hints with as
  • importlib — import_module(), reload(), LazyLoader
  • Circular imports — causes, error symptoms, avoidance strategies (refactor, import inside functions, restructure)
  • Best practices — PEP 8 import ordering, package layout, pitfalls: from x import *, side effects, sys.modules inconsistency

17. Iterators & Generators ✅

  • Iterable vs iterator — the core distinction
  • The iterator protocol: __iter__(), __next__(), StopIteration
  • iter() and next() — manual iteration, next() with default
  • Built-in iterators: map(), filter(), zip(), enumerate(), reversed() — all lazy in Python 3
  • Custom class-based iterators with __iter__ + __next__
  • Generator functions with yield — automatic state preservation, StopIteration
  • Generator expressions — lazy counterparts of comprehensions, memory efficiency
  • yield from — delegating to sub-generators, flattening
  • Practical patterns: infinite sequences, data pipelines, batch processing, file chunking
  • itertools infinite iterators: count, cycle, repeat
  • itertools finite iterators: chain, islice, compress, groupby, takewhile/dropwhile, pairwise, zip_longest, accumulate, tee
  • itertools combinatorics: product, permutations, combinations, combinations_with_replacement
  • Iterator exhaustion — single-use vs reusable
  • Lazy vs eager evaluation trade-offs
