Core Concepts

Variable
A name that references an object. Created with =: name = "Alice". Variables are labels on objects, not containers.
Object Identity (id())
Every object has a unique identity (memory address). id(x) returns it. Never changes for the object's lifetime.
is
Identity comparison. a is b is True only when a and b reference the exact same object. Different from == (value comparison).
Mutable
An object whose value can change after creation. Examples: list, dict, set.
Immutable
An object whose value cannot change after creation. Examples: int, float, str, tuple, bool.
Assignment
Binds a name to an object: x = 5. The right side is evaluated first, then the name is bound to the result.
Augmented Assignment
Combines operation and assignment: x += 1. For mutable objects, may operate in-place. Equivalent to x = x + 1 but x is evaluated only once.
Tuple Unpacking
Assigning multiple variables from an iterable: a, b, c = [1, 2, 3] or swapping: a, b = b, a.
Star Unpacking
Using * to capture remaining items: first, *rest = [1, 2, 3] → first=1, rest=[2, 3].
Type Annotation
Syntax for hinting variable types: name: str = "Alice". Ignored at runtime but used by linters and type checkers.
del
Removes a name binding (not the object itself). The object persists if other names reference it.
snake_case
Naming convention for Python variables and functions: lowercase with underscores between words. my_variable_name.
Truthiness
Every object's boolean value. False: None, False, zero, empty sequences/collections. Everything else is True.
Numeric Types
int (unlimited precision), float (double-precision), complex (real + imag). All immutable.
Sequence Types
Ordered collections with index access. list (mutable), tuple (immutable), range (immutable, memory-efficient).
Set Types
Unordered collections of unique, hashable elements. set (mutable), frozenset (immutable, hashable).
Mapping Type
dict — key-value pairs, insertion-ordered (3.7+), keys must be hashable.
Binary Types
bytes (immutable), bytearray (mutable), memoryview (zero-copy buffer access).
isinstance()
Checks if an object is an instance of a type: isinstance(x, int). Preferred over type(x) is int because it handles subclasses correctly.
Hashable
An object with a hash value that never changes. Immutable types are hashable. Required for dict keys and set elements. Lists and dicts are NOT hashable.
String (str)
Text data, enclosed in quotes: "hello" or 'hello'. Strings are sequences of Unicode code points, immutable, and hashable.
Integer (int)
Whole numbers: 42, -7, 0.
Float (float)
Decimal numbers: 3.14, -0.5.
Boolean (bool)
Truth values: True or False.
f-string
String interpolation with f"..." and {} placeholders: f"Hello, {name}".
Function
A reusable block of code. Called with (): print("hi").
print()
Built-in function that outputs text to the console.
input()
Built-in function that reads a line of text from the user. Returns a string.
type()
Built-in function that returns the type of a value: type(42) → <class 'int'>.
REPL
Read-Eval-Print Loop. Interactive Python shell. Start with python in terminal.
Script
A .py file containing Python code, run with python filename.py.
Comment
Code ignored by Python. Starts with #. Used for notes.

Operator Concepts

Short-Circuit Evaluation
Logical and/or stop evaluating as soon as the result is determined. False and x never evaluates x. True or x never evaluates x.
Chained Comparisons
Python allows a < b < c instead of a < b and b < c. Each middle operand is evaluated only once.
Operator Precedence
The order in which Python evaluates operators in an expression. From highest: **, unary +-~, *///%, +-, shifts, bitwise, comparisons, not, and, or (lowest).
Operator Overloading
Operators like + behave differently based on operand types because types define special methods (e.g., __add__). int.__add__ does arithmetic; str.__add__ concatenates.
Right-Associativity
Some operators evaluate right-to-left. ** is right-associative: 2 ** 3 ** 2 = 2 ** (3 ** 2) = 2 ** 9 = 512.

Control Flow

if Statement
Runs a block only if a condition is truthy: if x > 0: print("positive"). Always ends with a colon.
elif
Short for "else if". Chains an additional condition after an if. Checked only if all previous conditions were false.
else
Fallback branch — runs when no if or elif condition was true. Optional, must be last.
Ternary Expression
One-line conditional: value_if_true if condition else value_if_false. Returns a value.
match/case
Structural pattern matching (Python 3.10+). Compares a subject against patterns. Supports literals, | for multiple patterns, _ as wildcard, and guards (if). More powerful than if/elif for complex matching.
Guard
An extra condition in a match/case pattern: case (x, y) if x == y:. Must be true for the case to match.
pass
No-op statement. Does nothing. Used as a placeholder where syntax requires a statement. Also useful in loop bodies you haven't implemented yet.

Loops

for Loop
Iterates over an iterable (list, string, tuple, etc.) one element at a time. Unlike C/JavaScript, does not use an index by default: for fruit in fruits: print(fruit).
while Loop
Repeats as long as a condition is truthy: while count < 5: count += 1. Use when number of iterations is unknown.
range()
Built-in function that generates an arithmetic progression of numbers. Lazy (memory-efficient). Forms: range(stop), range(start, stop), range(start, stop, step). The stop value is exclusive.
break
Exits the innermost enclosing for or while loop immediately.
continue
Skips the rest of the current loop iteration and moves to the next one.
Loop else
An optional else clause on for and while loops. Runs only if the loop completed without hitting a break. Does not run if loop was terminated by break, return, or an exception.
enumerate()
Built-in that adds a counter to an iterable. Yields (index, value) tuples. Preferred over range(len(seq)). Accepts a start parameter (default 0).
zip()
Built-in that pairs elements from multiple iterables, stopping at the shortest. Often used with for: for a, b in zip(list1, list2):.
dict.items()
Returns a view of key-value pairs. Used in loops: for k, v in person.items():. The preferred way to iterate over both keys and values.
dict.values()
Returns a view of values only. Used in loops: for v in person.values():. Preserves insertion order (Python 3.7+).
Set iteration
Looping over a set yields elements in arbitrary (unpredictable) order. Use sorted(set) for ordered iteration: for x in sorted(myset):.
reversed()
Built-in that returns a reverse iterator over a sequence. Useful in loops: for x in reversed(seq):.
sorted()
Built-in that returns a new sorted list from an iterable. Leaves the original unchanged. Common in loops: for x in sorted(iterable):.
Loop variable scoping
Python's for loop variable leaks into the enclosing scope and retains its value after the loop ends. This differs from C/Java where the variable is local to the loop.
Nested Loop
A loop inside another loop. The inner loop runs all its iterations for each iteration of the outer loop. Common for 2D data (matrices, grids).
Iterable
An object capable of returning its elements one at a time. Examples: list, string, tuple, dict, set, range, file handle. Can be used in a for loop or with iter().

Strings

String indexing
Individual characters accessed by position: s[0] (first), s[-1] (last). Zero-based. Negative indices count from the end.
String slicing
Extract a substring: s[start:stop:step]. Stop is exclusive. All bounds are optional. Never raises an error — out-of-bounds indices are silently clamped. s[::-1] reverses the string.
String immutability
Strings cannot be modified in place. s[0] = "x" raises TypeError. All operations return a new string. This makes strings hashable (usable as dict keys / set elements).
.upper() / .lower()
Return a new string with all characters converted to uppercase/lowercase. "Hello".upper() → "HELLO".
.capitalize() / .title()
.capitalize() uppercases the first character only. .title() uppercases the first character of each word.
.swapcase()
Swaps uppercase ↔ lowercase: "Hello".swapcase() → "hELLO".
.casefold()
Aggressive lowercasing for caseless matching. More thorough than .lower() for non-ASCII text (e.g., German ß → ss).
.find() / .rfind()
Return the lowest/highest index where a substring is found. Returns -1 if not found. Accepts optional start and end range.
.index() / .rindex()
Like .find() / .rfind() but raises ValueError if substring is not found.
.count()
Returns the number of non-overlapping occurrences of a substring: "ababa".count("aba") → 1.
.replace()
Returns a copy with all occurrences of a substring replaced: "cat cat".replace("cat", "dog") → "dog dog". Optional count limits replacements.
.startswith() / .endswith()
Check if a string starts/ends with a given substring. Accepts a tuple of options: "file.txt".endswith((".txt", ".md")).
.removeprefix() / .removesuffix()
Python 3.9+. Remove a leading/trailing substring if present: "https://x.com".removeprefix("https://") → "x.com".
.split() / .rsplit()
Split a string into a list using a delimiter. Default splits on any whitespace (and discards empty strings). maxsplit limits the number of splits. rsplit splits from the right.
.join()
Concatenates an iterable of strings using the separator string: ", ".join(["a", "b", "c"]) → "a, b, c". Called on the separator, not the list. The idiomatic way to combine strings.
.partition() / .rpartition()
Split a string at the first/last occurrence of a separator. Returns a 3-tuple: (before, separator, after). Always returns three elements.
.splitlines()
Split on line boundaries (\n, \r\n, etc.). Optional keepends=True preserves the line break characters.
.strip() / .lstrip() / .rstrip()
Remove leading/trailing characters (default: whitespace). " hello ".strip() → "hello". Can specify chars to remove: "...hello...".strip(".") → "hello".
.center() / .ljust() / .rjust()
Pad a string to a given width. "hi".center(7) → " hi ". Optional fillchar (default space).
.zfill()
Left-pad with zeros to a given width. Sign-aware: "-5".zfill(5) → "-0005".
.expandtabs()
Replace tab characters (\t) with spaces, respecting tab stops. Default tab size is 8.
Classification methods (is*)
12 methods that check string content: .isalpha() (letters only), .isdigit() (digits only), .isalnum() (letters and digits), .isspace() (whitespace only), .islower() / .isupper() (case check), .istitle() (titlecased), .isascii() (all chars ASCII), .isidentifier() (valid Python identifier), .isprintable() (no control chars), .isdecimal() (decimal digits), .isnumeric() (any numeric including fractions/Roman). All return False for empty strings.
ord()
Built-in function that returns the Unicode code point (integer) of a character: ord("A") → 65, ord("😀") → 128512. Inverse of chr().
chr()
Built-in function that returns the character for a Unicode code point: chr(65) → "A". Inverse of ord(). Raises ValueError if the integer is out of valid Unicode range.
f-string format specifier
After the colon in an f-string expression: f"{value:width.precision type}". Examples: :.2f (2 decimal places), :>10 (right-align width 10), :^10 (center), :b (binary), :x (hex).
f-string debug (=)
Python 3.8+. f"{var=}" prints var=value. Useful for quick debugging: f"{name=} {age=}" → "name='Alice' age=30".
f-string conversion (!r, !s, !a)
!r applies repr(), !s applies str() (default), !a applies ascii() (escapes non-ASCII). f"{text!r}" → "'hello\\nworld'".
Raw string (r"...")
A string prefix that treats backslashes as literal characters. No escape sequences are processed. Essential for regular expressions (r"\d+\.\d+") and Windows paths (r"C:\Users\name"). Can combine with f-strings: rf"{value}".
Triple-quoted string
A string delimited by """ or ''' that spans multiple lines. Used for docstrings and long text blocks. Leading/trailing whitespace is preserved unless using textwrap.dedent().
Docstring
A triple-quoted string as the first statement in a function/class/module. Accessible via help() and obj.__doc__. Standard convention for documentation.
Unicode code point
An integer in the Unicode codespace, ranging from 0 to 0x10FFFF (1,114,111). Each character maps to a code point. Represented in Python with \u (16-bit), \U (32-bit), or \N{name} escapes.
.encode() / .decode()
.encode(encoding) converts a str to bytes. .decode(encoding) converts bytes to str. Common encodings: "utf-8" (default), "utf-16", "latin-1", "ascii". Error handling: "strict" (default, raises), "ignore", "replace" (adds ?), "xmlcharrefreplace".
bytes vs str
In Python 3, str holds Unicode text, bytes holds raw byte data. They are distinct types and cannot be mixed: "hello" + b" world" raises TypeError. Convert explicitly with .encode() / .decode() at program boundaries.
Unicode escape sequences
\u00e9 → é (16-bit), \U0001F600 → 😀 (32-bit), \N{GREEK SMALL LETTER PI} → π (named). Used in normal and raw strings to represent characters by their code point.

Lists

List (list)
A mutable ordered sequence. Lists can hold items of any type, including mixed types. Constructed with [], list(), or list comprehensions.
Slice assignment
Assigning to a slice of a list: lst[1:3] = [10, 20]. Can change the length of the list (unlike string slicing). With step, the assigned iterable must match the slice length.
.append(x)
Adds x to the end of the list. Returns None. Equivalent to lst[len(lst):len(lst)] = [x].
.extend(iterable)
Extends the list by appending all items from the iterable. Returns None. More efficient than repeated append().
.insert(i, x)
Inserts x at index i. a.insert(0, x) inserts at the front. a.insert(len(a), x) is equivalent to a.append(x). Returns None.
.remove(x)
Removes the first occurrence of x. Raises ValueError if not found. Returns None.
.pop(i=-1)
Removes and returns the item at index i (default: last item). Raises IndexError on empty list. The only list method that both modifies the list AND returns a value.
.clear()
Removes all items from the list. Equivalent to del lst[:]. Returns None. Added in Python 3.3.
.index(x[, start[, end]])
Returns the zero-based index of the first occurrence of x. Raises ValueError if not found. Optional start and end limit the search range.
.count(x)
Returns the number of times x appears in the list.
.sort(*, key=None, reverse=False)
Sorts the list in place using < comparisons. Returns None. key is a function that extracts a comparison key. The sort is stable (equal elements keep original order). Raises TypeError if items can't be compared.
sorted()
Built-in function that returns a new sorted list from any iterable. Unlike .sort(), it works on any iterable and leaves the original unchanged. Same key and reverse parameters.
Sort stability
Python's sort (Timsort) preserves the original order of elements that compare equal. This enables multi-key sorting: sort by secondary key first, then primary key — the stable sort preserves the secondary ordering within equal primary keys.
List comprehension
A concise syntax for creating lists: [expression for item in iterable if condition]. Equivalent to a for loop with append(), but faster and more readable. Supports nested loops: [x for row in matrix for x in row].
Nested list comprehension
A list comprehension where the expression is itself a list comprehension. Used for 2D data: [[row[i] for row in matrix] for i in range(4)] transposes a matrix.
Stack (LIFO)
Last-In, First-Out data structure. Python lists naturally implement stacks via .append() (push) and .pop() (pop). Both are O(1) operations at the end of the list.
Queue (FIFO)
First-In, First-Out data structure. Using a list (.pop(0)) is inefficient (O(n)). Use collections.deque with .append() and .popleft() for O(1) operations at both ends.
collections.deque
A double-ended queue with O(1) appends and pops from both ends. Supports .append(), .appendleft(), .pop(), .popleft(), .rotate(). Can be bounded with maxlen. The recommended structure for queues and sliding windows.
del on lists
del lst[i] removes an item by index. del lst[i:j] removes a slice. del lst deletes the variable entirely. Unlike .pop(), del does not return the removed value.
Shallow copy
A copy of a list where the new list references the same objects as the original. Created by .copy(), [:], or list(original). For nested lists, modifying an inner list affects both copies.
Deep copy
A fully recursive copy where all nested objects are also copied. Created by copy.deepcopy(lst). The new list shares no references with the original. Necessary for nested/multidimensional lists.
[[]] * n trap
Creating a list of lists by repetition: [[]] * 5 creates a list where all elements are the same list object. Modifying one "row" modifies all. Fix: use a list comprehension: [[] for _ in range(5)].
Modifying during iteration
Adding or removing items from a list while iterating over it causes items to be skipped. Fix: iterate over a copy (for x in lst.copy():) or use a list comprehension to build a new list.
array.array
A memory-efficient array of typed values. Type codes: 'i' (int), 'f' (float), 'd' (double), etc. Supports most list operations but stores values compactly. Best for large numeric datasets. Not for heterogeneous data.

Tuples

Tuple (tuple)
An immutable ordered sequence. Tuples are created by commas, not parentheses: t = 1, 2, 3. Used for heterogeneous fixed records, dict keys, and multiple return values.
Tuple packing
The automatic creation of a tuple when values are separated by commas: packed = 1, 2, 3 creates (1, 2, 3). The comma is the tuple operator, not the parentheses.
Sequence unpacking
Assigning multiple variables from any sequence: a, b, c = (1, 2, 3) or a, b, c = [1, 2, 3] or x, y = "hi". Works on any iterable, not just tuples.
Starred unpacking
Using * to capture remaining elements during unpacking: first, *rest, last = range(10). rest becomes a list of middle elements. Can be empty.
Single-element tuple
A tuple with one element requires a trailing comma: (1,). Without the comma, (1) is just the integer 1 grouped by parentheses. The comma disambiguates.
Tuple immutability
Tuples cannot be modified after creation: no item assignment, no appending, no deletion of items. However, if a tuple contains a mutable object (like a list), that object's contents can change: t[0].append(99) works if t[0] is a list.
.count(x)
Tuple method that returns the number of occurrences of x: (1, 2, 2, 3).count(2) → 2.
.index(x[, start[, end]])
Tuple method that returns the index of the first occurrence of x. Raises ValueError if not found. Optional start and end limit the search range.
Tuple concatenation (+)
Creates a new tuple by combining two tuples. Each + creates a new object. Building a large tuple with repeated + in a loop has quadratic cost — build a list first, then convert with tuple().
Tuple repetition (*)
Creates a new tuple by repeating the contents n times: (1, 2) * 3 → (1, 2, 1, 2, 1, 2). Mutable elements are referenced, not copied — same trap as [[]] * n for lists.
Lexicographic comparison
Tuple comparison works element by element from left to right. (1, 2, 3) < (1, 2, 4) → True (first difference at index 2). Shorter sequences are considered smaller if all elements match: (1, 2) < (1, 2, 3) → True. This enables natural multi-key sorting with tuples as sort keys.
Tuple hashability
A tuple is hashable (can be used as a dict key or set member) only if all of its elements are hashable. A tuple containing a list is not hashable. This property follows from tuple immutability — because the tuple can't change, its hash is stable.
Composite key
A dictionary key made from multiple values, combined into a tuple: grades[("Alice", "Math")] = 95. Useful when no single value uniquely identifies a record.
Named tuple (namedtuple)
A factory function from collections that creates tuple subclasses with named fields. Instances are indexable (like regular tuples) and support attribute access: p.x instead of p[0]. Lightweight — no per-instance dict, same memory as regular tuples.
namedtuple._make(iterable)
Class method on a named tuple that creates an instance from an iterable: Point._make([3, 4]) → Point(x=3, y=4).
namedtuple._asdict()
Instance method that returns an OrderedDict mapping field names to values: p._asdict() → {'x': 3, 'y': 4}.
namedtuple._replace(**kwargs)
Instance method that returns a new named tuple instance with specified fields replaced: p._replace(x=99) → Point(x=99, y=4). The original is unchanged (tuples are immutable).
namedtuple._fields
Class attribute — a tuple of strings listing the field names: Point._fields → ('x', 'y'). Useful for introspection and creating new named tuple types by combining fields.
namedtuple._field_defaults
Class attribute — a dict mapping field names to their default values. Defaults are applied to the rightmost fields. Account._field_defaults → {'balance': 0}.

Dictionaries

Dictionary (dict)
A mutable mapping from keys to values. Keys must be hashable (immutable). Values can be any type. Preserves insertion order (Python 3.7+). Provides O(1) average access time.
Dict literal ({})
Creating a dict with curly braces: {"a": 1, "b": 2}. Empty braces {} create an empty dict (not a set).
dict() constructor
Creates a dict from keyword arguments: dict(a=1, b=2), from a sequence of pairs: dict([("a", 1), ("b", 2)]), or from zip: dict(zip(keys, vals)).
Insertion order
Python 3.7+ guarantees that dicts preserve the order in which keys were first inserted. Iterating, .keys(), .values(), and .items() all follow insertion order. popitem() removes the most recently inserted item (LIFO).
d[key] — bracket access
Returns the value for key. Raises KeyError if the key does not exist. For safe access, use d.get(key).
d[key] = value
Assigns a value to a key. If the key exists, its value is updated. If the key is new, it is inserted (at the end of the insertion order).
del d[key]
Removes a key-value pair from the dict. Raises KeyError if the key does not exist.
key in d
Membership test — returns True if the key exists in the dict. O(1) average time. Use not in for the inverse.
.get(key[, default])
Returns the value for key if it exists, otherwise returns default (or None if no default is given). Never raises KeyError. Does NOT insert the default into the dict.
.pop(key[, default])
Removes the key and returns its value. If the key is missing, returns default if provided, otherwise raises KeyError.
.popitem()
Removes and returns a (key, value) pair. In Python 3.7+, removes the most recently inserted item (LIFO). Raises KeyError on an empty dict.
.setdefault(key[, default])
If key is in the dict, returns its value (without modifying). If key is not in the dict, inserts key with default and returns default. Unlike .get(), this DOES modify the dict when the key is missing.
.update([other])
Merges key-value pairs from another dict, iterable of pairs, or keyword arguments. Overwrites existing keys. Returns None. Similar to |= operator (Python 3.9+).
.clear()
Removes all items from the dict. The dict object still exists (unlike del d which deletes the variable).
.copy()
Returns a shallow copy of the dict. The new dict references the same objects as the original. For nested dicts, use copy.deepcopy().
fromkeys(iterable, value)
Class method that creates a new dict with keys from iterable and all values set to value. ⚠️ If value is mutable (e.g., []), all keys share the same object. Fix: use a dict comprehension.
Dict view (.keys(), .values(), .items())
Dynamic view objects that reflect changes to the dict in real time. .keys() and .items() support set-like operations (&, |, -, ^). .values() does not (values may not be hashable).
dict.keys()
A view of all keys in insertion order. Supports set operations: intersection (&), union (|), difference (-), symmetric difference (^). Dynamic — updates when the dict changes.
dict.values()
A view of all values in insertion order. Does NOT support set operations (values are not guaranteed to be hashable, and equality comparison between value views is always False by design).
dict.items()
A view of all (key, value) pairs in insertion order. Supports set operations (if values are hashable). This is the preferred way to iterate over both keys and values: for k, v in d.items():.
Dict view .mapping attribute
Python 3.10+. Returns the underlying dict from a dict view. d.keys().mapping is d → True. Useful for passing the actual dict through when only a view is available.
Dict comprehension
Concise syntax for creating dicts: {k: v for k, v in iterable}. Supports filtering with if, transformation, and nested loops. Examples: {x: x**2 for x in range(10)}, {v: k for k, v in original.items()}.
Merge operator (|)
Python 3.9+. Creates a new dict by merging two dicts. Right-hand dict wins on duplicate keys: merged = d1 | d2. The original dicts are unchanged.
Update operator (|=)
Python 3.9+. Updates a dict in place (mutation): d1 |= d2. Equivalent to d1.update(d2) but more readable.
Nested dict
A dict where values are themselves dicts: {"Alice": {"Math": 95}}. Accessed with chained brackets: d["Alice"]["Math"]. Common for hierarchical data like gradebooks, configs, or JSON-like structures.
__missing__(self, key)
A special method on dict subclasses. Called by __getitem__ (bracket access) when a key is not found. defaultdict implements this hook. Regular dicts do NOT support __missing__.
collections.defaultdict
A dict subclass that calls a factory function to supply missing values. Common factories: list (grouping), int (counting), set (unique grouping), lambda: value (custom default). Only applies to __getitem__ — .get() still returns None for missing keys.
defaultdict(list)
Auto-creates an empty list for each missing key. Pattern: dd[key].append(value). The idiomatic way to group items by category. More concise than setdefault(key, []).append(value).
defaultdict(int)
Auto-creates 0 for each missing key. Pattern: dd[key] += 1. The easiest way to count occurrences.
collections.Counter
A dict subclass for counting hashable objects. Returns 0 for missing keys (no KeyError). Key methods: .most_common(n), .elements(), .total() (3.10+), .subtract(). Supports arithmetic: +, -, &, |, unary +/-. .update() adds counts (unlike regular dict which replaces).
Counter.most_common([n])
Returns a list of the n most common elements and their counts, sorted from most to least. If n is omitted, returns all elements. c.most_common(1)[0][0] gets the single most common element.
Counter.elements()
An iterator over elements repeating each as many times as its count. Elements are returned in arbitrary order. Use sorted(c.elements()) for ordered output.
Counter.total()
Python 3.10+. Returns the sum of all counts. Equivalent to sum(c.values()).
Counter arithmetic
+ adds counts (union of multiset sums). - subtracts counts (keeps only positive results). & takes the minimum (intersection). | takes the maximum (union). Unary + removes non-positive counts. Unary - returns only negative counts as positives.
collections.OrderedDict
A dict subclass that remembers insertion order (now mostly redundant with Python 3.7+ dicts). Unique features: move_to_end(key, last=True), order-sensitive equality (regular dicts ignore order), popitem(last=False) (pop from beginning), reinserting a key moves it to the end.
OrderedDict.move_to_end(key, last=True)
Moves an existing key to the end (if last=True) or to the beginning (if last=False). Raises KeyError if the key is missing. Useful for implementing LRU caches.
OrderedDict.popitem(last=True)
Removes and returns a (key, value) pair. With last=True (default), pops from the end (LIFO). With last=False, pops from the beginning (FIFO). On a regular dict, popitem() always pops from the end.
Mutating during dict iteration
Adding or removing keys while iterating over a dict raises RuntimeError: dictionary changed size during iteration. Fix: iterate over a copy: for k in list(d): or for k in d.copy():.

Sets

Set (set)
An unordered collection of unique, hashable elements. Mutable. Supports O(1) membership testing and mathematical set operations. Created with {1, 2, 3} or set(). The empty set must be created with set() — {} creates an empty dict.
frozenset
An immutable version of a set. Created with frozenset(iterable). Supports all non-mutating set operations (|, &, -, ^, <=, etc.) but not .add(), .remove(), etc. Hashable — usable as dict keys and set members.
Hashable element requirement
Set elements must be hashable (immutable). int, float, str, tuple (of hashables), and frozenset are allowed. list, dict, and set are not hashable and cannot be set elements.
Empty set trap
{} creates an empty dictionary, not a set. To create an empty set, use set(). A non-empty set literal like {1, 2, 3} works correctly because Python distinguishes it from a dict by the absence of colons.
.add(x)
Adds element x to the set. If x already exists, the set is unchanged (no error). Returns None.
.remove(x)
Removes element x from the set. Raises KeyError if x is not present. Use when the element is expected to exist.
.discard(x)
Removes element x from the set if present. Does NOT raise an error if x is missing. Use when absence is acceptable.
.pop()
Removes and returns an arbitrary element from the set. Since sets are unordered, you cannot predict which element is removed. Raises KeyError on an empty set.
Set union (|)
Returns a new set with all elements from both sets. {1, 2, 3} | {3, 4, 5} → {1, 2, 3, 4, 5}. Method form: .union(other) accepts any iterable.
Set intersection (&)
Returns a new set with elements common to both sets. {1, 2, 3} & {2, 3, 4} → {2, 3}. Method form: .intersection(other).
Set difference (-)
Returns a new set with elements in the left set but not in the right. {1, 2, 3} - {2, 4} → {1, 3}. Order matters. Method form: .difference(other).
Symmetric difference (^)
Returns a new set with elements in either set but not both. {1, 2, 3} ^ {3, 4, 5} → {1, 2, 4, 5}. Method form: .symmetric_difference(other).
Subset (<=)
a <= b is True if all elements of a are in b. Method form: .issubset(b).
Proper subset (<)
a < b is True if a <= b and a != b. A set is NOT a proper subset of itself.
Superset (>=)
a >= b is True if all elements of b are in a. Method form: .issuperset(b).
.isdisjoint(other)
Returns True if the set has no elements in common with other. The sets are "disjoint" if their intersection is empty.
Set update (.update() / |=)
Adds all elements from another set (or iterable) to this set. Mutates in place. Returns None. The |= operator requires a set operand; .update() accepts any iterable.
Set comprehension
Concise syntax for creating sets: {expression for item in iterable if condition}. Automatically deduplicates. Example: {x**2 for x in range(10)} creates a set of squares.
Set iterability
Looping over a set yields elements in arbitrary order. Use sorted(myset) for deterministic ordered iteration: for x in sorted(myset):.

Functions

Function definition (def)
A compound statement that creates a function object and binds it to a name: def name(params): body. The body is not executed at definition time — only when the function is called.
Function call (())
Executes a function by appending parentheses to the function name: func(). Arguments are passed inside the parentheses: func(arg1, arg2).
Parameter
A variable listed in the function definition's parentheses. Receives the argument value when the function is called. Parameters are local to the function.
Argument
A value passed to a function when calling it. Arguments are assigned to the function's parameters. Can be positional or keyword.
Positional argument
An argument passed in the order of the function's parameters: f(1, 2, 3). The position determines which parameter receives it.
Keyword argument
An argument passed with an explicit parameter name: f(name="Alice", age=30). Order doesn't matter. Must follow positional arguments in a call.
Default argument value
A value specified in the function definition that is used when the argument is omitted: def f(x=10):. Evaluated once at definition time — hence the mutable default trap.
Mutable default trap
A bug where a mutable default argument (like lst=[]) is shared across all calls because it's created once at function definition time. Fix: use lst=None and assign a new list inside the function.
Positional-only parameter (/)
Parameters before / in the function definition cannot be passed as keyword arguments: def f(a, b, /, c):. Useful when parameter names have no semantic meaning or for API stability.
Keyword-only parameter (*)
Parameters after * in the function definition must be passed as keyword arguments: def f(*, a, b):. Only f(a=1, b=2) is valid; f(1, 2) raises TypeError.
*args
Captures extra positional arguments into a tuple inside the function. Convention, not a keyword. Can be named anything (*numbers, etc.). Must appear before **kwargs.
**kwargs
Captures extra keyword arguments into a dict inside the function. Convention, not a keyword. Access values with kwargs["key"] or iterate kwargs.items().
Argument unpacking (* / ** in calls)
Unpacks an iterable into positional arguments (f(*lst)) or a dict into keyword arguments (f(**d)) when calling a function. The reverse of *args/**kwargs in definitions.
Forwarding pattern
A wrapper function that accepts *args, **kwargs and passes them through to another function: def wrapper(*args, **kwargs): return target(*args, **kwargs).
Docstring
A string literal as the first statement in a function. Accessible via func.__doc__ and help(func). PEP 257: one-line summary, blank line, then details. Triple-quoted strings are conventional.
Function annotation (type hint)
Optional metadata for parameter and return types: def f(x: int) -> str:. Stored in __annotations__. NOT enforced at runtime — used by linters, IDEs, and type checkers like mypy.
First-class function
Functions are objects. They can be assigned to variables, passed as arguments, returned from other functions, and stored in data structures. This enables decorators, callbacks, and higher-order functions.
callable()
Built-in function that returns True if the argument appears callable: callable(func) → True, callable(42) → False. Classes and objects with __call__ are also callable.
Lambda expression
An anonymous inline function: lambda x: x * 2. Restricted to a single expression (no statements or annotations). Used for short throwaway functions, especially with sorted(key=...), map(), filter().
Closure
A function that remembers variables from its enclosing scope even after that scope has finished executing. Created when a nested function references a variable from the enclosing function. Used for factory functions and decorators.
LEGB rule
Python's name resolution order: Local (current function), Enclosing (outer functions), Global (module level), Built-in (names like print, len). Python searches in this order when looking up a name.
global
A statement that tells Python a name refers to a global (module-level) variable: global x; x = 10. Required only when ASSIGNING to a global variable inside a function — reading globals works without it.
nonlocal
A statement that tells Python a name refers to a variable in the nearest enclosing function scope (not global): nonlocal count; count += 1. Used in nested functions. Required only when reassigning the enclosing variable.
map()
Built-in that applies a function to every item in an iterable, returning a lazy iterator: map(func, iterable). Often replaced by list comprehensions for readability, but useful with existing functions (no lambda) and for lazy evaluation.
filter()
Built-in that returns items from an iterable where the function returns True: filter(func, iterable). With None, removes falsy values: filter(None, items).
functools.reduce()
A function that cumulatively applies a function to items of an iterable, reducing it to a single value: reduce(lambda a, b: a * b, [1, 2, 3, 4]) returns 24. Lives in the functools module (not built-in in Python 3).
Recursion
A function that calls itself. Every recursive function needs a base case (stops the recursion) and a recursive case (calls itself with a smaller problem). Examples: factorial, tree traversal, divide-and-conquer algorithms.
Recursion limit
Python's limit on the number of nested function calls (default 1000). Exceeding it raises RecursionError. Check with sys.getrecursionlimit(), change with sys.setrecursionlimit(n). Python does not optimize tail recursion.
Call stack
The data structure that tracks function calls. Each call pushes a frame (with local variables) onto the stack. When a function returns, its frame is popped. The call stack has a limited depth (see recursion limit).

Comprehensions

Comprehension
A concise syntax for creating collections from iterables. Python has three comprehension types (list, dict, set) plus generator expressions. All follow the pattern: expression for variable in iterable if condition.
List comprehension
Syntax: [expr for var in iterable if cond]. Creates a new list eagerly by mapping/filtering an iterable. More Pythonic than map()/filter() for simple cases. Example: [x**2 for x in range(10) if x % 2 == 0].
Dict comprehension
Syntax: {key_expr: val_expr for var in iterable if cond}. Creates a new dict. Example: {word: len(word) for word in words}.
Set comprehension
Syntax: {expr for var in iterable if cond}. Creates a new set (deduplicated, unordered). Example: {len(w) for w in words}.
Generator expression (genexp)
Syntax: (expr for var in iterable if cond). Returns a lazy iterator that produces values on demand — NOT a collection. Memory-efficient for large data. Single-use (exhausted after iteration). Example: sum(x**2 for x in range(10_000_000)).
Lazy evaluation
Computing values only when needed, not in advance. Generator expressions use lazy evaluation — they produce one value at a time as requested, instead of building an entire collection in memory. Opposite of eager evaluation (list comprehensions).
Nested comprehension
A comprehension whose expression is itself a comprehension. Used for 2D data: [[row[i] for row in matrix] for i in range(4)] transposes a matrix. Also refers to comprehensions with multiple for clauses: [(x, y) for x in [1, 2] for y in [3, 4]].
Walrus operator (:=)
Assignment expression operator (Python 3.8+). Allows assigning a value within an expression. In comprehensions, useful for computing a value once and reusing it in both the filter and the output: [n for x in data if (n := expensive(x)) > 10].
Cartesian product
In comprehensions, using multiple for clauses produces the Cartesian product of the iterables. Each element of the first is paired with every element of the second, and so on. Total elements = product of all iterable lengths.

Error Handling

Exception
An event that disrupts normal program flow. Python raises exceptions when it encounters an error. If unhandled, the program terminates with a traceback. All exceptions inherit from BaseException.
Traceback
The report Python prints when an unhandled exception terminates a program. Shows the call stack from most recent to oldest, with file paths, line numbers, and the lines of code that led to the error. Read from bottom to top — the last line is the root cause.
try/except
Catches exceptions. Code in the try block runs first; if an exception occurs, the matching except block runs. Can catch specific exception types: except ValueError:. Multiple except blocks are checked in order.
except as e
Binds the caught exception to a variable for inspection: except ValueError as e:. The variable is scoped to the except block (Python 3.12+) or leaks afterward (older Python). Use type(e).__name__ and e.args for details.
try/else
The else block runs if the try block completed without raising an exception. It does NOT run if an exception was caught or if the try block had a return/break/continue.
try/finally
The finally block always runs — whether an exception occurred or not, and even if return, break, or continue was executed. Used for cleanup (close files, release locks). Python 3.14 warns if return appears in finally (PEP 765).
raise
Explicitly triggers an exception. Forms: raise ValueError("msg") (new exception), raise (re-raise current exception in except block), raise X from Y (chain exceptions, sets __cause__).
Exception chaining (raise ... from)
Preserves the original exception as the __cause__ of the new one. Both exceptions appear in the traceback. raise ... from None suppresses the original traceback, useful when the new exception is more meaningful.
assert
Debugging aid that raises AssertionError if the condition is False: assert x > 0, "x must be positive". Disabled with -O flag. Not for validation that must always run — use a regular if + raise instead.
Custom exception
A user-defined exception class inheriting from Exception (or a more specific built-in). Convention: name ends with Error for runtime errors. Should provide a sensible __init__ that accepts relevant context.
EAFP (Easier to Ask Forgiveness than Permission)
A Python coding style: try the operation and handle exceptions if they occur. More idiomatic than LBYL in Python. Example: try: d["key"] except KeyError: instead of if "key" in d:.
LBYL (Look Before You Leap)
The opposite of EAFP: check conditions before performing an operation. More common in C/Java. In Python, EAFP is preferred because it avoids TOCTOU (Time of Check to Time of Use) races and duplicate lookups.
Bare except:
An except clause without an exception type. Catches ALL exceptions, including KeyboardInterrupt and SystemExit (which inherit from BaseException, not Exception). Use except Exception: instead to avoid catching system-exit signals.
ExceptionGroup / except*
Python 3.11+. ExceptionGroup wraps multiple unrelated exceptions into one. except* handles exceptions by type within a group, letting different handlers handle different exceptions from the same try block. Unhandled exceptions propagate as a new ExceptionGroup.
BaseException.add_note()
Python 3.11+. Attaches extra context text to an exception instance. Notes appear below the traceback when the exception is printed: e.add_note("context"). Multiple notes can be added and are shown in order.
Context manager
An object that sets up a resource and tears it down automatically, used via the with statement. Implements __enter__ (setup, returns resource) and __exit__ (teardown, handles exceptions). Examples: file handles via open(), locks, database connections.
with statement
Syntax for using a context manager: with open("file.txt") as f:. The manager's __enter__ is called, the body runs, then __exit__ is called even if the body raised an exception. Supports multiple managers (Python 3.10+): with A() as a, B() as b:.
__enter__ / __exit__
Magic methods for context managers. __enter__(self) sets up and returns the resource. __exit__(self, exc_type, exc_val, exc_tb) tears down and decides whether to suppress exceptions (return True to suppress).
@contextmanager
A decorator from contextlib that turns a generator function into a context manager. Code before yield is __enter__, the yielded value is the as target, code after yield is __exit__. Any exception in the body is re-raised at the yield point.
contextlib.suppress
A context manager that suppresses specified exceptions: with suppress(FileNotFoundError): os.remove("file"). More explicit than try/except: pass — it makes the intent clear that you expect and ignore certain errors.
PEP 765 — return in finally
Python 3.14 introduces a SyntaxWarning when return appears inside a finally block. This is dangerous because it can silently swallow exceptions — the return value takes precedence over any pending exception, hiding bugs.

File I/O

open()
Built-in function that returns a file object. Syntax: open(filename, mode='r', encoding=None). Modes: r (read), w (write, truncates), a (append), x (exclusive create), b (binary), + (read+write). Always use with with statement.
Context manager (with statement)
Guarantees file is closed after the block, even if exceptions occur. Syntax: with open("file.txt") as f:. The f.close() is called automatically. Always use this instead of manual close.
File modes
r: read (default, file must exist). w: write (truncates existing). a: append (adds to end). x: exclusive create (fails if exists). b: binary mode. +: read+write. Combine: rb, w+, ab.
Text vs binary mode
Text mode (default): reads/writes strings, applies encoding/decoding, translates newlines. Binary mode (b): reads/writes bytes objects, no encoding, no newline translation. Use binary for images, audio, or any non-text data.
Encoding
The character encoding used for text files. Always specify encoding="utf-8" explicitly. Default is platform-dependent (locale encoding). Python 3.15+ makes UTF-8 the default (PEP 686).
f.read(size)
Reads from file. Without argument: entire file. With size: up to that many characters (text) or bytes (binary). Returns empty string/bytes at EOF.
f.readline()
Reads one line from the file. Includes trailing \n (except possibly last line). Returns empty string at EOF. Blank lines return '\n', not empty string.
f.readlines()
Reads all lines and returns a list of strings. Each element includes trailing \n. Memory-intensive for large files — prefer iteration.
f.write(string)
Writes string to file. Returns number of characters written (text mode) or bytes written (binary mode). Does NOT add newlines — you must include \n explicitly.
f.writelines(lines)
Writes a sequence of strings to the file. Does NOT add newlines between items — each string should include \n if needed.
f.tell()
Returns current position in file (bytes from beginning). In text mode, position is opaque but can be used with seek().
f.seek(offset, whence)
Moves file position. whence=0: from beginning (default). whence=1: from current. whence=2: from end. In text mode, only seek(0) and seek(0, 2) are guaranteed safe.
f.flush()
Forces buffered data to be written to disk. Files are buffered for efficiency. flush() writes the buffer without closing the file. Called automatically by close().
f.closed
Returns True if the file is closed, False otherwise. Check after exiting with block to verify closure.
Newlines
Line endings differ by platform: \n (Unix), \r\n (Windows), \r (old Mac). Python's universal newlines (default) translate all to \n on read. newline='' disables translation. CSV files require newline=''.
pathlib.Path
Object-oriented path representation (Python 3.4+). Preferred over os.path. Create: Path("file.txt"). Join with /: Path("dir") / "file.txt". Properties: .name, .stem, .suffix, .parent.
Path.read_text() / Path.write_text()
Convenience methods for reading/writing text files. p.read_text(encoding="utf-8") reads entire file. p.write_text("content") writes string. Also available: read_bytes(), write_bytes().
Path.glob() / Path.rglob()
Find files by pattern. glob("*.py") matches in current directory. rglob("*.py") matches recursively in all subdirectories.
os.stat()
Returns file metadata as stat_result. Attributes: st_size (bytes), st_mtime (modification time), st_ctime (creation/change time), st_mode (permissions/type).
os.scandir()
Efficient directory listing that returns DirEntry objects with cached metadata. 2-20x faster than os.listdir() + os.stat(). Use when you need file type or size.
os.walk()
Recursive directory traversal. Yields (dirpath, dirnames, filenames) for each directory. topdown=True (default) for top-down, topdown=False for bottom-up (useful for deletion).
glob.glob()
Finds files by shell-style pattern. Supports * (any characters), ? (single char), [range]. recursive=True enables ** to match any depth.
shutil module
High-level file operations. copy()/copy2(): copy files. copytree(): copy directories. move(): move files/dirs. rmtree(): delete directories recursively (dangerous!).
shutil.copy() vs shutil.copy2()
copy(): copies content + permissions. copy2(): copies content + permissions + metadata (timestamps). Use copy2() when you want to preserve all file information.
tempfile module
Creates temporary files and directories. NamedTemporaryFile(): named temp file with .name attribute. TemporaryDirectory(): temp dir with auto-cleanup. Both support context managers.
io.StringIO / io.BytesIO
In-memory streams. StringIO(): text in memory. BytesIO(): binary in memory. Both support read(), write(), seek(), tell(). Use for testing or building content before writing to disk.
csv module
Handles CSV file reading/writing. csv.reader(): returns rows as lists. csv.DictReader(): returns rows as dicts. csv.writer()/csv.DictWriter(): write CSV. Always open CSV files with newline=''.
json module
Handles JSON data. json.dump()/json.load(): file I/O. json.dumps()/json.loads(): string I/O. indent for pretty printing. ensure_ascii=False for Unicode. Python types map: dict→object, list→array, str→string, int/float→number, True/False/None→true/false/null.
JSON serialization
Converting Python objects to JSON strings. json.dumps(obj) serializes. Non-serializable types (datetime, custom objects) need a default function that returns a serializable representation.
Binary files
Files containing non-text data (images, audio, compiled code). Open with b mode (rb, wb). Read/write bytes objects, not strings. No encoding or newline translation.
Buffering
Data is buffered in memory for efficiency. flush() writes buffer to disk. close() flushes then closes. with statement calls close() automatically. Use flush() when you need immediate disk write.
File object
An object returned by open() that provides methods for reading/writing. Also called a "file handle" or "stream". Supports iteration (line by line), context manager protocol, and has properties like .closed.

Modules & Packages

Module
A .py file containing Python code. The file name (minus .py) becomes the module name. Each module has its own private namespace. Any .py file is automatically a module.
Package
A special kind of module that contains submodules or subpackages. Identified by having a __path__ attribute. All packages are modules, but not all modules are packages.
import statement
The statement that searches for a named module and binds it in the local namespace. Forms: import x, import x.y.z, from x import y, from x import *, import x as y, from . import y.
from x import y
Loads module x, then binds y directly in the current namespace. No prefix needed to use y. Works for submodules, functions, classes, and variables.
from x import *
Imports all public names from module x. What counts as "public" is determined by __all__ if defined, otherwise all names not starting with _. Only allowed at module level. Generally discouraged due to namespace pollution.
Absolute import
An import using the full dotted path from the top-level package: from mypackage.sub import mod. Always clear where the import comes from.
Relative import
An import using leading dots to navigate relative to the current package: from . import sibling, from .. import parent_module. One dot = current package, two dots = parent. Only works with the from form.
__name__
A special attribute on every module. Set to the module's fully qualified name when imported (e.g., "json"), or "__main__" when the module is executed directly.
if __name__ == "__main__"
A pattern that makes a file usable both as an importable module and as a standalone script. The code inside the block only runs when the file is executed directly, not when imported.
__init__.py
A file that marks a directory as a regular Python package. Executed when the package is imported. Can set __all__, re-export submodules, or be empty. Optional for namespace packages (Python 3.3+).
Namespace package
A package that exists without __init__.py, allowing a single package to be split across multiple directories on sys.path. Has a dynamic, read-only __path__ attribute. Slower to import than regular packages.
sys.path
A list of directories that Python searches for modules. Initialized from the script's directory, PYTHONPATH, and installation defaults (including site-packages). Can be modified at runtime.
sys.modules
A dictionary mapping module names to module objects. Serves as the import cache — the first place checked during import. If a module is found here, it's returned immediately without re-execution.
PYTHONPATH
An environment variable containing a list of directories to add to sys.path. Set it in the shell to make custom modules importable from anywhere.
site-packages
The directory where third-party packages are installed (e.g., via pip). Automatically added to sys.path by the site module.
dir()
Built-in that returns a sorted list of names. Without arguments: names in the current scope. With a module argument: names defined in that module. Useful for exploring modules interactively.
hasattr(obj, name)
Built-in that returns True if obj has an attribute called name. More readable than name in dir(obj) for checking if a module defines a specific name.
__all__
A list of strings in a module that defines which names are exported by from module import *. If not defined, all names not starting with _ are exported. Used in packages to define the public API.
Re-export
Making an imported name available to users of your package. Done by importing in __init__.py and including the name in __all__, or by using from X import Y as Y (explicit re-export for type checkers).
__spec__
A ModuleSpec encapsulating all import-related information. Recommended way to access module metadata. Attributes: .name, .origin, .parent, .loader, .submodule_search_locations. Introduced in Python 3.4 (PEP 451).
__path__
A list of directories where a package's submodules will be found. Present only on packages (not plain modules). Non-package modules don't have this attribute. By definition, any module with __path__ is a package.
importlib
Standard library module that provides tools for programmatic importing. Key functions: import_module() (dynamic import from string), reload() (re-execute module code), invalidate_caches().
importlib.import_module(name)
The recommended way to dynamically import a module from a string name. Returns the module object. importlib.import_module("math") is equivalent to import math but works with a runtime string.
importlib.reload(module)
Re-executes a module's code without creating a new module object. The module dictionary is retained — names not redefined keep old values. Existing from X import Y references are NOT updated. Not thread-safe.
Circular import
When two or more modules depend on each other at import time. Can cause AttributeError if one tries to use a name that hasn't been defined yet. Fix by importing inside functions, refactoring shared code, or restructuring dependencies.
Lazy import
Deferring the actual import until the module is first used. Python provides importlib.util.LazyLoader for explicit lazy loading. Reduces startup time for heavy modules that may not be needed.
Module namespace
Each module has its own global namespace (module.__dict__). Functions defined in a module use the module's namespace as their global namespace, preventing accidental name clashes between modules.

Iterators & Generators

Iterable
An object capable of returning its elements one at a time. Has an __iter__() method that returns an iterator. Examples: list, str, tuple, dict, set, range, file objects. Can be used in a for loop or with iter(). NOT the same as an iterator.
Iterator
An object representing a stream of data. Implements both __iter__() (returns self) and __next__() (returns next element or raises StopIteration). Single-use — once exhausted, it cannot be reused. All iterators are iterables, but not vice versa.
Iterator protocol
The contract that makes for loops work. Consists of __iter__() (returns the iterator) and __next__() (returns next value, raises StopIteration when done). The for loop calls iter() on the container, then next() repeatedly until StopIteration.
StopIteration
An exception raised by __next__() to signal that an iterator has no more values. Caught internally by for loops. Also raised by generators when they finish. Can carry a return value in StopIteration.value.
iter()
Built-in function that returns an iterator from an iterable. Also used in for loops internally. With a callable and sentinel: iter(callable, sentinel) calls the callable until it returns the sentinel.
next()
Built-in function that advances an iterator and returns the next element. Raises StopIteration if exhausted. With a second argument: next(iterator, default) returns default instead of raising.
Generator function
A function that contains yield. When called, returns a generator object (not executing the body). The body runs incrementally on each next() call. Local variables and execution state are automatically preserved between calls. StopIteration is raised automatically when the function ends. Much simpler than writing a class-based iterator.
yield
A keyword that turns a function into a generator. yield x outputs x and suspends execution. On the next next() call, execution resumes after the yield. Unlike return, yield preserves local state and can be called multiple times.
yield from
An expression that delegates iteration to a sub-generator (Python 3.3+). yield from subgen yields all values from subgen and forwards send(), throw(), and close() calls. Simplifies generator composition, flattening, and chaining.
Generator expression (genexp)
A lazy, single-use iterable created with parentheses instead of square brackets: (expr for x in iterable if cond). Returns a generator object. Memory-efficient for large datasets. Often used inline in function calls: sum(x**2 for x in range(10)).
Lazy evaluation
Computing values only when needed, not in advance. Generators and generator expressions use lazy evaluation. Map, filter, zip, enumerate are all lazy in Python 3. Saves memory and can handle infinite sequences.
Iterator exhaustion
An iterator can only be consumed once. After all values have been yielded (or extracted via next()), the iterator is exhausted and will raise StopIteration on further attempts. To iterate again, create a new iterator or materialize to a list.
Infinite iterator
An iterator that never raises StopIteration. Created by generator functions with while True: yield x or by itertools.count(), itertools.cycle(), itertools.repeat(). Must be used with truncation (break, islice, takewhile) or risk infinite loops.
itertools
Standard library module providing fast, memory-efficient iterator building blocks. Combines into an "iterator algebra" for constructing specialized tools. Categories: infinite iterators, finite iterators, and combinatoric iterators.
itertools.count(start=0, step=1)
Infinite iterator that returns evenly spaced values starting with start. Supports floats. Useful with map() for consecutive data points or zip() for numbering. Never stops — always pair with islice or takewhile.
itertools.cycle(iterable)
Infinite iterator that saves a copy of the iterable and cycles through it forever. Useful for alternating patterns, round-robin behavior. Stores the entire iterable in memory for the cycling phase.
itertools.repeat(elem, [n])
Infinite (or bounded) iterator that returns the same element repeatedly. Common use: supplying constant values to map() or zip(). With n, stops after n repetitions.
itertools.chain(*iterables)
Returns an iterator that concatenates iterables. chain("AB", "CD") → A B C D. Flattens one level. chain.from_iterable(iterable) chains from nested iterables.
itertools.islice(iterable, start, stop [, step])
Returns selected elements from an iterator, like sequence slicing. Does NOT support negative indices. Consumes the input up to the stop position. Essential for working with infinite iterators.
itertools.compress(data, selectors)
Filters data by a parallel boolean selector. compress("ABCDEF", [1,0,1,0,1,1]) → A C E F. Useful for filtering one iterable by patterns in another.
itertools.groupby(iterable, key=None)
Returns consecutive keys and groups from an iterable. The iterable MUST already be sorted by the key function. Unlike SQL's GROUP BY, only groups consecutive equal keys. The returned group is itself an iterator shared with the parent.
itertools.takewhile(pred, seq) / dropwhile(pred, seq)
takewhile yields elements as long as predicate is true, then stops. dropwhile skips elements while predicate is true, then yields all remaining. Both consume the failing element.
itertools.pairwise(iterable)
Returns successive overlapping pairs (Python 3.10+). pairwise("ABCDE") → AB BC CD DE. The output has one fewer element than the input.
itertools.zip_longest(*iterables, fillvalue=None)
Like zip() but continues until the longest iterable is exhausted, filling missing values with fillvalue. Use for pairing uneven-length sequences.
itertools.tee(iterable, n=2)
Splits an iterator into n independent iterators. May use significant memory if one iterator runs far ahead of others. If one iterator consumes all data before others start, prefer list() instead.
itertools.accumulate(iterable, func=operator.add, *, initial=None)
Returns running totals or running results of any binary function. accumulate([1,2,3,4]) → 1 3 6 10. With initial, the output has one more element than the input (Python 3.8+).
itertools.product(*iterables, repeat=1)
Cartesian product of input iterables. Equivalent to nested for-loops. product("AB", repeat=2) → AA AB BA BB. Consumes all inputs eagerly into tuples.
itertools.permutations(iterable, r=None)
All possible r-length orderings (permutations) of the input. Order matters, no repeated elements. If r is omitted, defaults to full length. permutations("ABC", 2) → AB AC BA BC CA CB.
itertools.combinations(iterable, r)
All r-length subsequences (combinations) of the input. Order does NOT matter, no repeated elements. combinations("ABC", 2) → AB AC BC. Elements are treated as unique by position, not value.
itertools.combinations_with_replacement(iterable, r)
All r-length subsequences where elements can repeat. combinations_with_replacement("ABC", 2) → AA AB AC BB BC CC.
Generator pipeline
A data processing chain composed of chained generators. Each generator transforms data one item at a time, and no intermediate collections are created. Memory-efficient for large datasets. Example: read lines → parse → filter → extract → aggregate.
Coroutine
A generator enhanced with .send(), .throw(), and .close() methods. send(value) passes a value into the generator (the value becomes the result of yield). Must be "primed" with next() first. This is the foundation of async/await in Python.

OOP — Classes & Objects

Class
A blueprint for creating objects. Defines attributes (data) and methods (behavior). Created with the class keyword. Classes are first-class objects in Python — they can be assigned to variables, passed as arguments, and stored in data structures.
Object
An instance of a class. Created by calling the class like a function: obj = MyClass(). Each object has its own identity (id()), type (type()), and value (its attributes).
Instance
Synonym for "object" when referring to a specific creation of a class. alice is an instance of the Person class. An instance has its own attributes that can differ from other instances of the same class.
__init__
The initialization method (constructor) called automatically when a class is instantiated. Sets up the initial state of the instance. Must accept self as the first parameter. Called after __new__ creates the instance.
self
The first parameter of instance methods. Represents the instance being operated on. Python passes it automatically when you call a method on an instance. Just a convention — could use any name, but always use self.
Instance attribute
An attribute unique to each instance. Created in __init__ or other methods with self.name = value. Stored in the instance's __dict__. Different instances can have different values for the same attribute.
Class attribute
An attribute shared across all instances of a class. Defined directly in the class body: class MyClass: x = 10. Stored in the class's __dict__. Modifying it affects all instances (unless an instance attribute shadows it).
Instance method
A function defined inside a class that operates on instance data. Takes self as the first parameter. Can access and modify instance attributes. Called on an instance: obj.method().
Class method
A method that receives the class (cls) instead of the instance. Created with the @classmethod decorator. Can access class attributes but not instance attributes. Often used as alternative constructors (factory methods).
Static method
A function that lives inside a class's namespace but doesn't receive self or cls. Created with the @staticmethod decorator. A regular function that logically belongs with the class. Used for utility functions.
__str__
A special method that returns a human-readable string representation. Called by print(), str(), and f-strings. Should return a user-friendly string. Falls back to __repr__ if not defined.
__repr__
A special method that returns an unambiguous, developer-friendly string representation. Called by repr(), interactive display, and debugging. Should ideally be a valid Python expression that recreates the object. Always define this; __str__ is optional.
Public
An attribute or method with no underscore prefix. Part of the class's public API. Accessible from anywhere. This is the default visibility in Python.
Protected
An attribute or method with a single underscore prefix (_attr). Convention signaling "internal use." Not enforced by Python — accessible from outside. Respected by from module import *.
Private
In Python, refers to name mangling with double underscores (__attr). Python transforms __attr in class MyClass to _MyClass__attr. Prevents naming conflicts in inheritance, NOT access control. Anyone can access the mangled name.
Name mangling
The automatic renaming of __attr to _ClassName__attr by Python. Designed to prevent accidental name collisions in inheritance hierarchies. Not a security feature — the mangled name is easily accessible.
@property
A decorator that turns a method into a managed attribute. Allows getter, setter, and deleter logic while maintaining clean attribute syntax. Use for validation, computation, or controlled access without changing the API.
Getter
A property method decorated with @property that returns the attribute value. Called when accessing the property: obj.attr. Can include validation or computation.
Setter
A property method decorated with @attr.setter that sets the attribute value. Called when assigning: obj.attr = value. Can include validation before storing the value.
__slots__
A class attribute that restricts attribute creation and eliminates the per-instance __dict__. Saves memory (~40-50% reduction). Syntax: __slots__ = ('x', 'y'). Trade-off: no dynamic attributes.
Dataclass
A class decorated with @dataclass that auto-generates __init__, __repr__, __eq__, and other methods. Reduces boilerplate for data container classes. From the dataclasses module (Python 3.7+).
Descriptor
An object that defines __get__, __set__, or __delete__ methods to control attribute access. Properties, class methods, static methods, and __slots__ all use descriptors internally. Data descriptors (with __set__) take priority over instance dictionaries.
Factory method
A class method that creates and returns an instance of the class, often with a different signature than __init__. Example: Date.from_string("2024-01-15"). Useful for alternative construction patterns.

OOP — Inheritance & Polymorphism

Inheritance
A mechanism where a new class (child/derived) adopts attributes and methods from an existing class (parent/base). Enables code reuse and models "is-a" relationships. Syntax: class Child(Parent):.
Parent / Base Class
The class being inherited from. Provides attributes and methods that child classes can reuse or override. Also called superclass.
Child / Derived Class
The class that inherits from a parent. Can add new attributes/methods or override parent methods. Also called subclass.
super()
A built-in function that returns a proxy for calling parent methods. Most commonly used in __init__ to call the parent's constructor: super().__init__(...). In Python 3, takes no arguments.
Method Resolution Order (MRO)
The order Python searches for methods in a class hierarchy. Determined by C3 linearization. View with ClassName.__mro__ or ClassName.mro(). Ensures each class is visited exactly once in diamond hierarchies.
Multiple Inheritance
A class inheriting from more than one parent: class Child(Parent1, Parent2):. Powerful but can cause complexity. Python uses C3 linearization to handle method resolution.
Diamond Problem
A situation in multiple inheritance where a child inherits from two parents that share a common ancestor. Without careful MRO, methods from the common ancestor could be called multiple times. C3 linearization prevents this.
Mixin
A class that provides reusable methods for other classes but is not meant to be instantiated directly. Conventionally named with Mixin suffix. Used to add orthogonal functionality (logging, serialization, etc.) in a composable way.
Abstract Base Class (ABC)
A class that defines an interface using @abstractmethod decorators. Cannot be instantiated directly — subclasses must implement all abstract methods. From abc.ABC or abc.ABCMeta.
@abstractmethod
A decorator from abc that marks a method as abstract. Subclasses must override it. Can be applied to methods, properties, classmethods, and staticmethods. Should be the innermost decorator when combined with others.
Virtual Subclass
A class registered with an ABC using ABC.register() without inheriting from it. Makes isinstance() and issubclass() return True, but does NOT enforce abstract method implementation.
__subclasshook__
A classmethod on ABCs that customizes issubclass() behavior. Can check for specific methods in a class's __dict__ or __mro__ to determine subclass relationship dynamically.
Duck Typing
A programming style where an object's suitability is determined by the presence of certain methods/properties, not its type. "If it walks like a duck and quacks like a duck, it's a duck." Python's preferred polymorphism approach.
Polymorphism
The ability to use a unified interface for different data types. In Python, achieved through duck typing — any object with the right methods works, regardless of its class hierarchy.
isinstance()
Built-in function that checks if an object is an instance of a class (or tuple of classes). Respects inheritance: isinstance(dog, Animal) is True if Dog inherits from Animal. Preferred over type() is.
issubclass()
Built-in function that checks if a class is a subclass of another (or tuple). issubclass(Dog, Animal) is True if Dog inherits from Animal. Returns True for transitive relationships.
Liskov Substitution Principle (LSP)
A principle stating that objects of a subclass should be substitutable for objects of the parent class without breaking the program. Subclasses should not strengthen preconditions or weaken postconditions.
Template Method Pattern
A design pattern where a base class defines an algorithm skeleton with abstract "hook" methods. Subclasses implement the hooks while the base class controls the overall flow. Uses inheritance to vary steps.
Composition
A design approach where objects contain other objects to reuse functionality ("has-a" relationship) instead of inheriting ("is-a"). Often preferred over inheritance for flexibility and avoiding deep hierarchies.

OOP — Magic Methods & Protocols

Magic method (dunder method)
A special method with double underscores (__name__) that Python calls behind the scenes. Implementing these lets your objects participate in built-in operations like arithmetic, comparison, iteration, and context management. Never call them directly — use normal syntax instead.
NotImplemented
A special singleton returned from binary operators when the operation is not supported. Signals Python to try the right operand's reflected method. Different from NotImplementedError (an exception class).
Protocol
A set of magic methods that define a behavior (e.g., sequence protocol = __len__ + __getitem__). If your object implements the protocol's methods, it works with Python's built-in functions that use that protocol — regardless of its actual type.
__repr__
Returns an unambiguous, developer-friendly string representation. Called by repr(), interactive display, and debugging. Should be a valid Python expression that recreates the object if possible. Always define this.
__str__
Returns a human-readable string representation. Called by str(), print(), and f-strings. Falls back to __repr__ if not defined. Optional — use when you want friendlier output than __repr__.
__format__
Controls the output of format(obj, spec) and f-string format specs: f"{obj:spec}". Lets you define custom format specifications for your objects. Called after __str__ when a format spec is provided.
Binary operator
An operator that takes two operands: x + y. Python first tries x.__add__(y). If that returns NotImplemented, it tries y.__radd__(x). If both fail, raises TypeError.
Reflected (right-hand) operator
The right operand's version of a binary operator: __radd__, __rsub__, etc. Called when the left operand's method returns NotImplemented. Enables 0 + vector when int.__add__ doesn't know about vectors.
In-place operator
Operators like +=, -=, *= that modify objects in place. Implemented via __iadd__, __isub__, etc. Should return self for in-place modification, or a new object if in-place isn't feasible. Falls back to x = x + y if not defined.
Unary operator
An operator that takes one operand: -x (__neg__), +x (__pos__), abs(x) (__abs__), ~x (__invert__).
@functools.total_ordering
A class decorator that generates the missing comparison methods from just __eq__ and one of __lt__, __le__, __gt__, __ge__. Saves writing all six methods manually.
__hash__
Returns the hash value for the object, used for dict keys and set membership. Must be consistent: if x == y, then hash(x) == hash(y). Defining __eq__ without __hash__ sets __hash__ to None (unhashable).
__len__
Returns the length of the container (must be >= 0). Called by len(). If defined without __bool__, objects with length 0 are falsy.
__getitem__
Enables bracket access: obj[key]. Handles indexing, slicing (with slice objects), and dict-like access. Raises IndexError for out-of-range sequence indices, KeyError for missing dict keys.
__setitem__
Enables bracket assignment: obj[key] = value. Used for mutable sequences and mappings.
__delitem__
Enables bracket deletion: del obj[key]. Used for mutable sequences and mappings.
__contains__
Enables membership testing: item in obj. If not defined, Python falls back to __iter__, then __getitem__ with integer indices starting from 0.
__iter__
Returns an iterator for the object. Called by for loops and iter(). If defined with __getitem__ using sequential integers, the class is iterable even without __iter__ (legacy protocol).
__next__
Returns the next item from an iterator. Raises StopIteration when exhausted. Together with __iter__, forms the iterator protocol.
__reversed__
Returns a reverse iterator. Called by reversed(obj). If not defined, falls back to __len__ + __getitem__.
__missing__
Called by dict.__getitem__() when a key is not found in a dict subclass. Used by defaultdict. Regular dicts don't support this hook.
__bool__
Returns the boolean value of the object. Called by bool(), if, while. If not defined, falls back to __len__ (truthy if nonzero). If neither is defined, all instances are truthy.
__call__
Makes instances callable like functions: obj(). Useful for stateful functions, strategy patterns, decorators, and functors. Objects with __call__ pass callable() checks.
__enter__
Sets up a context manager. Called at the start of a with block. The return value is bound to the as variable. Part of the context manager protocol.
__exit__
Tears down a context manager. Called at the end of a with block (always, even on exceptions). Receives exc_type, exc_val, exc_tb (all None if no exception). Return True to suppress the exception, False/None to let it propagate.
__getattr__
Called only when normal attribute lookup fails with AttributeError. Used for fallback/default attribute values. Not called for attributes that exist in __dict__ or the class.
__getattribute__
Called unconditionally for every attribute access on the instance. Must call object.__getattribute__(self, name) internally to avoid infinite recursion. Rarely overridden.
__setattr__
Called for every attribute assignment: self.name = value. Use object.__setattr__(self, name, value) inside it to actually set attributes (avoids infinite recursion).
__delattr__
Called for every del self.name. Use object.__delattr__(self, name) inside it to actually delete attributes.
Attribute lookup order
For obj.name: 1) Data descriptors, 2) Instance __dict__, 3) Non-data descriptors, 4) Class variables (via MRO), 5) __getattr__ as fallback.
__slots__
A class attribute that restricts attribute creation and eliminates the per-instance __dict__. Saves memory (~40-50% reduction) and improves attribute access speed. Syntax: __slots__ = ('x', 'y'). Trade-off: no dynamic attributes.
Dataclass
A class decorated with @dataclass that auto-generates __init__, __repr__, __eq__, and other methods. Reduces boilerplate for data container classes. From the dataclasses module (Python 3.7+).
field()
A function from dataclasses that provides fine-grained control over individual fields: default, default_factory (for mutable defaults), init, repr, compare, hash, metadata, kw_only.
__post_init__
A method called at the end of a dataclass's generated __init__. Used for computed fields, validation, or any logic that needs all fields set first.
InitVar
A pseudo-field in dataclasses that is passed to __init__ and __post_init__ but not stored as an actual field. Useful for parameters needed during initialization only.
asdict()
A dataclass helper that recursively converts a dataclass instance to a dict. Nested dataclasses are also converted. asdict(obj) returns a dict of field_name → value.
astuple()
A dataclass helper that recursively converts a dataclass instance to a tuple. Nested dataclasses are also converted. astuple(obj) returns a tuple of values.
replace()
A dataclass helper that creates a new instance with specified fields replaced: replace(obj, field=value). The original is unchanged. Works with frozen dataclasses.
fields()
A dataclass helper that returns a tuple of Field objects describing each field: name, type, default, etc. Useful for introspection and serialization.
Descriptor protocol
An object that defines __get__, __set__, or __delete__ methods to control attribute access. Properties, classmethods, staticmethods, and __slots__ all use descriptors internally.
Data descriptor
A descriptor defining __get__ AND at least one of __set__/__delete__. Data descriptors take priority over instance __dict__ entries. Example: property.
Non-data descriptor
A descriptor defining only __get__. Can be overridden by instance __dict__ entries. Examples: classmethod, staticmethod, functools.cached_property.
